# 01. Ansible Fundamentals

Ansible is an **open-source automation and configuration management tool** used to automate provisioning, configuration, application deployment, and repetitive IT tasks.

## Why Ansible?

- **Agentless** — no Ansible agent required on managed nodes
- **Simple** — uses human-readable YAML
- **Idempotent** — repeated runs aim for the same desired state
- **SSH-based** — Linux/Unix nodes commonly use SSH
- **Scalable** — manage one server or thousands
- **Extensible** — modules, plugins, roles, and collections
